# LiebStore 🛒

E-commerce full stack desenvolvido com Next.js, Typescript e PostgreSQL, com foco em uma experiência de compra moderna, segura e escalável.

O projeto está sendo desenvolvido para aplicar conceitos avançados de desenvolvimento web, incluindo autenticação, gerenciamento de estado, persistência de dados, arquitetura full stack e integração entre frontend e backend.

## 🚧 Status do Projeto

Em Desenvolvimento

Atualmente Implementado:

- Estrutura inicial da aplicação com Next.js
- Layout responsivo
- Componentização com React
- interface utilizando ShadCN UI
- Estilização com Tailwind CSS
- Banco de dados PostgreSQL configurado
- ORM Prisma para gerenciamento do banco
- Modelagem de produtos, usuarios e carrinho
- Seed inicial de dados
- Listagem de produtos utilizando dados reais do banco
- Sistema de autenticação com Next Auth
- Carrinho de comprar persistido no banco de dados (ADD AND REMOVE)
- Criptografia de senha usando Bcrypt

# 🏗️ Arquitetura do Projeto

O projeto utiliza uma arquitetura baseada no App Router do Next.js, aproveitando:

- Server Components
- Server Actions
- TypeScript para maior segurança
- Prisma para comunicação com o banco
- Validação de dados utilizando Zod
